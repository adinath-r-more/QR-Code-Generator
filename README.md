# 📱 QR Code Generator

A simple and responsive **QR Code Generator website** built using **HTML, CSS, and JavaScript**.  
This project uses an **external QR Code API** to generate QR codes instantly from text or URLs.

---

## 🚀 Features
- Generate QR codes from text or URLs
- Uses a public QR Code API
- Instant QR code generation
- Clean and user-friendly interface
- Responsive design
- Beginner-friendly project

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- QR Code Generator API

---

## 🌐 Live Demo
👉 (https://adinath-r-more.github.io/QR-Code-Generator/)

---

## 📂 How It Works
1. Enter text or a URL in the input field  
2. Click on **Generate QR Code**  
3. The QR code is generated instantly using the API  

---

## 📡 API Used
This project uses a public QR Code API to generate QR codes dynamically.
